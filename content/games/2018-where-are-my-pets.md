**Description** :  
Where Are My Pets? is a logic puzzle game about finding your pets and other objects. Each room could hold several objects, and you use clues about how pairs of objects relate to work out which ones are really there.

**Released** : 2018

**Platform** :
- [HTML5](https://www.kongregate.com/games/Crescentyr/where-are-my-pets)

**Tech** :
- Haxe
- OpenFL

**My Role** : Programmer & Game Designer

The idea came from an old game I loved, *Inspector Parker*. I turned it into a web game with my friend [Crescentyr](https://crescentyr.com), who created the art and assets. I wrote all the code in Haxe and OpenFL, including the clue system and the puzzle logic, and we published the game on **Kongregate**.
